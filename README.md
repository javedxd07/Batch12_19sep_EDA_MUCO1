# MUC01 – Exploratory Data Analysis (EDA)

## Group 12 | KL University

This repository contains the **MUC01 Exploratory Data Analysis (EDA)** work completed by **Group 12** as part of the academic coursework at **KL University**.

The project focuses on understanding the given dataset through **data cleaning, exploratory analysis, statistical summaries, and data visualization** to identify meaningful patterns, relationships, and insights.

---

## 📌 Project Objective

The main objectives of this project are to:

* Understand the structure and characteristics of the dataset.
* Identify and handle missing, duplicate, and inconsistent data.
* Perform data cleaning and preprocessing.
* Conduct Exploratory Data Analysis (EDA).
* Analyze important variables and their relationships.
* Use visualizations to communicate important findings.
* Derive meaningful business/data-driven insights from the analysis.

---

## 🔍 Analysis Performed

The analysis includes the following major steps:

### 1. Data Understanding

* Dataset shape and dimensions
* Column names and data types
* Descriptive statistics
* Unique values and categorical variables

### 2. Data Cleaning

* Handling missing values
* Detecting duplicate records
* Identifying inconsistent or invalid values
* Data type corrections
* Preparing a clean dataset for analysis

### 3. Exploratory Data Analysis

#### Univariate Analysis

Analysis of individual variables using:

* Histograms
* Bar charts
* Box plots
* Frequency distributions

#### Bivariate Analysis

Analysis of relationships between variables using:

* Scatter plots
* Grouped comparisons
* Bar charts
* Other relevant visualizations

#### Correlation Analysis

* Identification of relationships between numerical variables
* Correlation matrix
* Heatmap visualization

### 4. Insights and Findings

The analysis is used to identify:

* Important trends and patterns
* Relationships between variables
* Outliers and unusual observations
* Factors that may influence business outcomes
